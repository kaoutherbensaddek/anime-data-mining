# Anime Data Mining Project 🎌

##  Project Overview
This project applies **data mining techniques** to an anime-related dataset sourced from Kaggle.
The objective is to explore anime content and user interaction data, discover hidden patterns,
and apply machine learning methods for analytical and exploratory purposes.

##  Dataset
- Source: Kaggle Anime Dataset
- Includes multiple data files containing:
  - Anime metadata (titles, genres, type, episodes)
  - User–anime interaction data (ratings)
  - Popularity and engagement metrics

##  Data Mining Methods Used
- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Feature Engineering
- Unsupervised Learning (Clustering)
- (Optional) Recommendation or Predictive Analysis

##  Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook
